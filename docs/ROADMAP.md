# FARX Roadmap

## Phase 1 — language core
- [x] Lexer and token model
- [x] Recursive-descent parser and AST
- [x] Interpreter and lexical environments
- [x] Variables, expressions, branches, loops, functions
- [x] CLI and starter test suite

## Phase 2 — engineering
- [ ] Static type checker
- [ ] Bytecode compiler and virtual machine
- [ ] Module resolver and deterministic package format
- [ ] Debugger, profiler, formatter, language server
- [ ] Fuzzing and security review

## Phase 3 — platform tooling
- [ ] FARX Studio desktop IDE
- [ ] Android runtime and signed APK pipeline
- [ ] Windows and Linux distributions
- [ ] UI, AUDIO, 2D and 3D standard libraries

## Phase 4 — ecosystem
- [ ] Versioned package registry
- [ ] Reproducible builds and dependency lockfiles
- [ ] Plugin API and documentation portal

A checkbox means planned or implemented as explicitly marked; it is not a claim
that future features already exist.
